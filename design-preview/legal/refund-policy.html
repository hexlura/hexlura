REFUND POLICY

This content is published and versioned by Hexlura admins. This mockup shows the general structure only — real copy is managed via the admin legal editor.

REFUNDS ARE SET PER EVENT

Each organiser sets their own refund policy for their event, shown clearly on the event page before you book. Hexlura does not set a single platform-wide refund window — always check the policy badge on the event page before purchasing.

THE FOUR POLICY TYPES

No Refunds

All sales are final for this event, except if the event itself is cancelled.

Up to 48 Hours Before

Refund requests must be made at least 48 hours before the event start time.

Up to 7 Days Before

Refund requests must be made at least 7 days before the event start time.

Always Available

This organiser accepts refund requests at any time before the event.

HOW TO REQUEST A REFUND

Go to My Bookings, open the relevant booking, and select "Request Refund." Your request is sent to the organiser for review — you'll be notified of the outcome by email and in your notifications inbox.

BOOKING FEES

Hexlura's booking fee is non-refundable in all cases except when the event itself is cancelled by the organiser.

IF AN EVENT IS CANCELLED

If an organiser cancels an event, all bookings (including booking fees) are automatically refunded in full to your original payment method.
